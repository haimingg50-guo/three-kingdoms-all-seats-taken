# 参照实现 V0.1

这是「三国全员在线」的第一份可运行代码。它不是规范的全部，它是规范里已经能被别人部署、入席、留下史书的那一层。

## 这一版真正结算的事

- 开局冻结配置，并用 C1–C7 与红线拒绝不合法的局。
- 三城窄门（洛阳、许昌、成都、建业）是手摆的四城。经典十二城也是手摆的城与道路，郡名来自公开史地，不是任何商业游戏的地图。其余规模仍是抽象州郡图。
- 二十名历史人物。能力值是为本实验新写的 1–20 刻度。
- 一人一席。市民名由词库生成，不能自选。
- 每回合一次指令：朝议、内政、外交、军令。到点结算，或在席者全部锁定后提前结算。
- 弹劾、流放、处决（公示后才执行）、举荐、让位、摄政、兵变。
- 结盟、停战、称臣、背盟、割地。契约违约记入史书。
- 去向：君主可臣服（保留封地与部众，城计入对方统一比例）或叛离；在职人物可投降献出所在城，部将可投奔或下野，在野人可出仕。加入必须对方在席君主同意，空席不代答，过一个回合未答就作废。离开不需要旧主同意。臣服信誉 -8，投降 -12，投奔、下野、叛离 -6。投降和投奔不带走兵力。人仍由原玩家操作，仍受永久死亡约束。
- 臣服表决：在席多于一人时，君主先发起一回合表决。在席一人一票，空席不计，赞成必须超过 2/3，刚好 2/3 不通过。通过后才把要约送给对方君主。反对者可以不随行，未通过时赞成者可以个人投奔。只剩君主一人，或守将献城投降，不表决。发起后冷却 3 回合。史书默认记名，实验日志始终留角色。
- 出征沿指挥顺位：主将、在席副将、君主代指挥、否则按预设固守或撤退。系统不挑选新的进攻目标。
- 移驻：已入席的在职人物给自己下令，沿相邻道路一回合一城，不占行动点，与出征等军令互斥，不带走城中兵力。下单和结算都要求出发城与目标城由自己的势力控制。同一回合里，内政先在下单时所在的城结算，然后才是外交、天灾、流民、出征和城破遣散，最后才移驻。人若已经死亡、被俘、或不在下单时的城里，移驻作废，不从新位置再走一格。同势力不必君主逐个批准。不能挪动空席或别人。换阵营仍要接收方在席君主同意。四种语言的说明在 [docs/move.md](move.md)。
- 战果公式公开，没有随机数。天时另有一颗开局写进史书的种子：季节按回合轮换，天气和天灾由局号、回合与种子经公开的 mulberry32 抽出，各阵营同一套。雪和冬日只增加少量行军折损，雨和涝只加重渡河与沿河，旱减产，晴只给屯田很小的加成。天灾只减粮或兵力，不使人物退场，不替空席下令。
- 减灾和内政共用行动点：修堤、积谷、医营、开渠、修路、赈济、观天。堤防、水渠和修路会失修下降。义仓有上限，每回合损耗，灾时先抵粮损。医营降低瘟疫减兵并缩短疫病。赈济给民心、功和信誉，对别的阵营只记信任，不替对方答应盟约。观天只把下一回合已经确定的天气写入史书。
- 人事同样走菜单：结义要双方互指，单挑可以不退场，火攻、离间、伪报按公开比较结算，犒赏花金。城破后退往自家城，没有城才被俘。悬赏和流民按公开阈值发生。空席不领功、不代答、不自动投诚。
- 空席固守，空席上的人物不会因为没人扮演而战死。已入席却缺席的人仍承担死亡风险。
- 经典十二城开局：许昌、建业各 1500 兵，成都 1400，洛阳 1000，无主城 850。流民在民心低于 36 时带走 3% 兵粮。守成是 4 回合。单挑分差仍是 8。
- 统一条件满足后进入守成。守住则进入纪念馆，主服停止。没有重开这一局的接口。
- 赛季到期无人统一，按版图结算，不宣布统一。
- 诺米克实验室只能改白名单上的数字，不能改仓库。
- 全量事件只追加。导出的日志以角色为索引，不含账号。
- 裁判令牌只能因作弊或骚扰冻结席位，不能改兵力，不能指定胜者，不能删史书。

## 写在配置里、这一版不结算的事

- 自然寿命。人物不会因年老退场。
- 房间制即时战术。战争在回合结算时一次算完。
- 把朝议决议自动合并进 Git 分支。

这些项若出现在配置里，界面会标明它们只是记录。

## 和规范草案的一处数字差别

草案里的经典角色池是 60。这份实现的具名历史人物是 20。经典档案因此使用 20。把 `role_pool_size` 调高，补上的是非历史低级武将，不是新编的历史人物。上限 80，是为了让一局的名册仍然读得完。

## 部署者要知道的边界

反多开在这一版是「一个会话一把席位」。它挡不住同一个人开两个浏览器。更强的设备核对应由部署者接在自己的裁判流程上，而不是藏进不可审计的后门。

自由发言只在 `free_talk_control` 一类档案里出现。弹劾罪状在任何档案里都不能手写。
