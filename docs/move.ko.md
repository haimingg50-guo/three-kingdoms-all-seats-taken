# 이주

[中文](move.md) · [English](move.en.md) · [日本語](move.ja.md)

재석한 군주, 부장, 군사가 자신에게 명한다. 지금 성에서 이웃한 길을 한 성 걷는다. 내정의 3점을 쓰지 않고, 점도 늘지 않는다. 출정, 단도, 주수와 함께할 수 없다. 군령은 한 장에 하나다.

명령을 낼 때, 떠나는 성과 들어가는 성 모두 자기 세력의 것이어야 한다. 결산 때 다시 본다. 성이 바뀌었거나, 길이 이웃이 아니거나, 죽었거나, 사로잡혔거나, 명령을 낸 성에 이미 없으면, 이 한 걸음은 무효다. 사람은 결산 때의 자리에 남는다. 적성을 가로지르지 않고, 흩어져 간 새 성에서 한 성 더 걷지 않는다. 병력은 원래 성에 남긴다.

한 회의 순서는 내정(명령을 낸 성에 작용) → 외교 → 재앙과 유민 → 출정과 성이 깨진 뒤의 흩어짐 → 이주. 같은 세력 안에서는 군주가 하나씩 승인하지 않는다. 빈 자리나 다른 실재 인물을 남이 옮기지 못한다. 진영을 바꾸려면 받는 쪽의 재석한 군주가 동의해야 한다.

명령을 잠그는 것은 봉하는 것뿐이다. 둔전 수확, 공성 승패, 성 색은 사서가 적은 뒤에 보여 준다. 새로고침해도 이미 본 회는 다시 틀지 않는다. 동작은 켜기, 적게, 끄기. 영상이 없어도 둘 수 있다. 곡식 검사 개념 조각은 정식 연출이 아니다.
