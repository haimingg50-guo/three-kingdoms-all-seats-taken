# 移驻

[English](move.en.md) · [日本語](move.ja.md) · [한국어](move.ko.md)

已入席的君主、部将或军师给自己下令。沿当前城的相邻道路走一城。不占那 3 点内政，也不另加行动点。和出征、单挑、驻守等军令互斥，一张单里只能留一种。

下单时，出发城和目标城都必须由自己的势力控制。结算时再查一次。城已易手、道路不邻、人已死亡、被俘，或人已经不在下单时的城里，这一步作废。人留在结算当时的位置，不会穿越敌城，也不会从被遣散到的新城再走一格。城中兵力留在原城。

同一回合的顺序是：内政（仍作用在下单时所在的城）→ 外交 → 天灾与流民 → 出征和城破遣散 → 移驻。同势力内不必君主逐个批准。不能替空席或另一名真人下这条军令。换阵营仍要接收方在席的君主同意。

提交只封存指令。屯田收成、攻城胜负、城色，都等史书写下之后才演。刷新不把已经看过的回合再播一遍。动画可以开、少、关。没有视频也能玩。验粮概念片不是正式演出。
