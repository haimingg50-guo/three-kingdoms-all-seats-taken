# 移駐

[中文](move.md) · [English](move.en.md) · [한국어](move.ko.md)

在席の君主、部将、軍師が自分に命じる。今いる城から隣の道を一城歩く。内政の 3 点は使わず、点も増えない。出征、単挑、駐守とは両立しない。軍令は一枚に一つ。

下令のとき、出発の城と目標の城はどちらも自勢力のものでなければならない。決算でもう一度見る。城が易わっていた、道が隣でない、死んだ、捕虜になった、あるいは下令のときの城にもういないなら、この一歩は無効。人は決算のときの位置に残る。敵城を通り抜けず、遣散された新城からもう一城は歩かない。兵は元の城に残す。

一つの回合の順は、内政（下令のときの城に作用する）→ 外交 → 天災と流民 → 出征と城破の遣散 → 移駐。同じ勢力の中では、君主が一つずつ批准しない。空席や別の真人を、他人が動かすことはできない。陣営を換えるには、受け取る側の在席する君主の同意が要る。

指令を定めるのは封ずるだけ。屯田の収穫、攻城の勝敗、城の色は、史書が書いてから演ずる。更新しても、すでに見た回合はもう一度流さない。動作は開、少、関。動画がなくても遊べる。検糧の概念片は正式な演出ではない。
