# 삼국 전원 접속

[中文](README.md) · [English](README.en.md) · [日本語](README.ja.md) · [기여](CONTRIBUTING.ko.md)

연출 없는 삼국. 규칙은 공개한다. 통일하면 서버는 닫힌다. 자리는 실존 인물이 앉는다. 빈 자리는 AI가 명령하지 않는다. 고전 한 회는 24시간. 사반 시연은 8분. 회를 빨리하는 것은 이 일의 방향이 아니다. 공식 온라인 서버는 없다. 복제한 뒤 자기 기계에서 실행한다.

이것은 스스로 배포할 수 있는 사회 실험이다. 『패왕의 대륙』이나 어떤 상업 게임의 복각이 아니다. 그 미술, 음악, 화면, 수치표, 지도를 쓰지 않는다. 삼국의 인물과 주군은 공공의 역사다. 여기서 잇는 것은 그것뿐이다.

저장소는 도구를 나눈다. 세계를 운영하지 않는다. 한 판을 다른 사람에게 열게 하는 사람은 그 자리의 법 책임을 진다. 이 일은 공식 서버를 두지 않고, 돈도 받지 않는다.

「공식이 없는 사회는 어떻게 스스로 짜이는가」를 살피는 일은, 자기 코드도 같은 방식으로 공개된 자리에 둔다. 갈래는 이어받을 수 있다. 사서는 지울 수 없다.

## 이 판에서 일어나는 일

역사의 자리가 열둘, 성이 넷, 아직 수색으로 드러나지 않은 재야 인물이 있다. 별명은 가져오지 않는다. 조조를 고르면 앞에는 조조만 있다.

매 회 명령을 한 번 낸다. 탄핵하거나 동의하고, 둔전하거나 수색하고, 맹을 맺거나 거절하고, 출정하거나 고수한다. 시각이 되면 한꺼번에 결산한다. 빈 자리는 성만 지킨다. 누구를 대신해 생각하지 않는다. 인물이 전사하거나 처형된 뒤 영원히 퇴장한다. 그 이름은 다음 사람에게 넘기지 않는다.

누군가 도성과 충분한 성을 쥐고, 나머지 주요 세력을 없애거나 칭신하게 한 뒤 수성까지 지키면, 이 판은 기념관에 들고 멈춘다. 통일을 불가능하게 만드는 스위치는 없다. 온 지도를 장악하는 비율 1은 배치 검사가 거부한다.

메뉴를 먼저 익히려면 사반을 연다. 사반은 자리를 바꿀 수 있다. 그 기록은 실험 자료가 되지 못한다.

## 이 자리에서 실행

Node.js 22.

```bash
npm install
npm test
npm run dev
```

브라우저에서 `http://127.0.0.1:4317`. 첫 화면에 실험국이 나온다. 처음 열 때 저장에 `demo` 가 없으면, 프로그램이 「제일호 실험국」을 스스로 쓴다. 문서는 `tabletop_demo` 다. 따로 된 씨앗 명령은 없다. 판은 `http://127.0.0.1:4317/world/demo`. 개발 서버는 `0.0.0.0:4317` 을 듣는다. 방화벽이 허락하면 같은 네트워크에서도 닿는다. 자료는 `data/tianxia.sqlite`. 이 파일을 복사하면 사서 한 부를 보관한 것이다. 파일 이름과 문서 식별자 `tianxia_classic`은 저장용 내부 이름이라, 게임 이름을 따라 바꾸지 않는다. 옛 저장이 어긋나지 않게 하기 위해서다.

이것은 자기 기계에서의 시연이다. 공중에 열어도 되는 서비스가 아니다. 신원은 브라우저의 `tx_session` 쿠키뿐이고 계정은 없다. 실험국은 이름을 먼저 누른 사람이 자리를 가진다. 쿠키를 잃으면 그 자리로 돌아가지 못한다. 회에는 배경 시계가 없다. 누군가 페이지를 열어야 밀린 결산이 따라온다. 빈도 제한은 이 한 프로세스의 메모리에 있다. 저장소에 WebSocket 은 없다. 포트를 공중망에 내놓지 마라.

판은 이 실험을 위해 새로 그린 8비트 타일과 사각파 소리다. 계절은 색을 바꾸어 나타낸다. 비, 눈, 안개, 가뭄은 점의 입자다. 16비트로 다시 그리지 않았다. 고전 열두 성은 손으로 놓았다. 인물마다 자기 점묘 입상이 있다. 상업 삼국 게임의 미술이나 곡은 쓰지 않는다. 화면 글자는 융합 픽셀(SIL OFL. `src/fonts/FONTS.md`). 간체 중국어, English, 日本語, 한국어는 오른쪽 위에서 바꾼다. 선택은 이 브라우저에 남는다. 기억한 선택이 없으면 브라우저 언어를 따른다. 중국어 표는 모두 간체 화면이다. 사서는 사건의 종류와 매개변수만 저장하고, 보는 사람의 언어로 문장을 쓴다. 오른쪽 위의 「소리」를 눌러야 소리가 난다. 천시 씨앗은 개국 사서에 적는다. 날씨는 공개된 알고리즘으로 다시 계산할 수 있다. 감재와 내정은 행동점을 같이 쓴다. 제방, 의창, 의영, 수로, 길은 공개된 배치에 있다. 가득 채워도 손실을 영으로 만들지 못한다. 결의, 단도, 계략, 포상, 유민, 계절 현상은 `docs/rules.ko.md`의 인사에 있다. 수색은 쇠, 나무, 가죽, 마초, 또는 돈주머니의 돈을 가져온다. 형제를 배운 뒤 단조한다. 탈것은 단조하지 않고 길들인다. 단도는 장비로 많아야 4를 더한다. 군대 결산은 더하지 않는다. 통일 뒤 기념관은 그 판에 이미 적힌 사람과 기록을 늘어놓는다. 연출 설명은 [docs/spectacle.ko.md](docs/spectacle.ko.md). `npm run sim`은 여섯 고정 자리로 대국을 다시 돌린다. 보고는 `docs/playtest-6bots.md`.

환경에 `DATABASE_URL`(`postgres://` 또는 `postgresql://`)이 있으면 Postgres를 쓴다. 없으면 SQLite.

재판 패는 개국 때 한 번만 보인다. 제일호 실험국에 재판을 두려면 시작 전에 `TIANXIA_REFEREE_TOKEN`을 둔다. 패가 얼릴 수 있는 것은 부정이나 괴롭힘뿐이고, 전황은 고치지 못한다.

## Docker

```bash
docker compose up --build
```

마찬가지로 4317을 듣는다. Compose의 서비스 이름은 `sanguo`다. 데이터베이스 파일은 그대로 `./data/tianxia.sqlite`다.

## 이미 되는 것

- 간체 중국어, English, 日本語, 한국어. 사서는 사건의 종류와 매개변수만 저장하고, 보는 사람의 언어로 문장을 쓴다.
- 창작 픽셀 판, 입상, 칩 음악. 글꼴은 Fusion Pixel, SIL OFL.
- 빈 자리는 성만 지킨다. 복속은 2/3을 넘은 뒤에 보낸다. 딱 2/3은 통과가 아니다. 가입은 받는 군주의 동의가 필요하다.
- 장비: 재료 수색, 구매, 형제 배우기, 단조, 탈것 길들이기, 입고 벗기, 군계에 헌납하고 받기. 손수 만든 기물은 이름을 붙이고 제작자를 적는다.
- 통일 뒤 기념관은 그 판에 이미 적힌 세력과 기록만 늘어놓는다.
- 세 연출의 픽셀 분경. 건너뛰기, 끄기, 절약, 파일이 없으면 픽셀로 돌아간다.

## 아직 없는 것

- 배포된 공개 대국은 없다. `npm run dev` 와 Docker 는 자기 기계에서 돈다.
- 「칼끝이 비를 빌다」와 「명장이 망치를 시험하다」에는 영상이 없다. 분경만 있다.
- 「주공이 군량을 살피다」에는 약 6초의 AI 개념 견본이 있다. [examples/spectacle/](examples/spectacle/README.ko.md). 게임은 스스로 재생하지 않는다. 목록 주소는 비어 있다. 견본은 고칠 수 있는 3차원 공정이 아니다.
- 참가자 사이의 시장은 없다. 군계는 스스로 남에게 주지 않는다. 탈것은 번식하지 않는다.
