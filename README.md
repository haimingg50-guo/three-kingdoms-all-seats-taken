# 三国全员在线

[English](README.en.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · [贡献](CONTRIBUTING.md)

没有导演的三国。规则公开，统一即关服。席位由真人坐。空席不由 AI 代为下令。经典局一回合 24 小时，沙盘演示是 8 分钟。加快回合不是这个项目的路线。这里没有官方在线服务器，克隆之后在自己的机器上运行。

这是一个可自部署的社会实验，不是《霸王的大陆》或任何商业游戏的复刻。它不使用那些作品的美术、音乐、界面、数值表和地图。三国人物与州郡属于公共历史，这是这里唯一继承的东西。

仓库分发工具，不运营世界。谁把一局部署给别人玩，谁承担当地法律下的责任。本项目不提供官方服务器，也不收费。

一个研究「没有官方的社会如何自组织」的项目，自己的代码也用同样的方式放在公开的地方：分叉可以继承，史书不能删。

## 这一局里会发生什么

十二个历史席位，四座城，外加尚未被搜索发现的在野人物。你不带昵称。选了曹操，前台就只有曹操。

每一回合提交一次指令：弹劾或附议，屯田或搜索，结盟或拒绝，出征或固守。到点统一结算。空着的席位只会守城，不会替你思考。人物战死或被处决之后永久退场，这个名字不会交给下一个人。

有人同时握住都城、足够的城池，并让其余主要势力灭亡或称臣，再守住守成期，这一局进入纪念馆并停止。没有把统一做成不可能的开关。控制全图（比例 1）会被配置校验拒绝。

想先把菜单走通，开一局沙盘。沙盘可以换席，日志不能当作实验数据。

## 本地运行

需要 Node.js 22。

```bash
npm install
npm test
npm run dev
```

浏览器打开 `http://127.0.0.1:4317`。首页会列出实验局。第一次打开时，如果库里还没有 `demo`，程序自己写入「第一号实验局」，档案是 `tabletop_demo`。没有单独的种子命令。棋盘在 `http://127.0.0.1:4317/world/demo`。开发服务器监听 `0.0.0.0:4317`，所以本机防火墙如果放行，局域网也能访问。数据在 `data/tianxia.sqlite`。复制这个文件就是备份一整部史书。文件名和档案标识 `tianxia_classic` 是存档用的内部名字，不跟着游戏名改，以免旧档对不上。

这是自己机器上的试玩，不是已经可以对公网开放的服务。身份只是浏览器里的 `tx_session` 饼干，没有账号。实验局谁先点名谁入席，饼干丢了就回不到那一席。回合没有后台计时器，要有人打开页面才会补结算。频率限制记在这一个进程的内存里。仓库里没有 WebSocket。详见各语言的贡献说明，不要把端口直接暴露到公网。

棋盘是原创的 8 位瓦片和方波音。季节用换色表示，雨雪雾旱是点阵粒子，没有改成 16 位。经典十二城是手摆的，每个人物有一张自己的点阵立绘。不使用任何商业三国游戏的美术或曲目。界面汉字用「融合像素字体」（SIL OFL，见 `src/fonts/FONTS.md`）。日文、韩文、英文各用同一字体的对应字形，也是 SIL OFL。右上角可以切换简体中文、English、日本語、한국어。选择记在这台浏览器里，没有记住时按浏览器语言，中文一律用简体。史书只存事件种类和参数，打开时按观看者的语言写成句子。点右上角「音 关」才会出声。天时种子写在开局史书里，天气可以按公开算法复算。减灾和内政共用行动点，堤防、义仓、医营、水渠和修路都写在公开配置里，叠满也不能把损失减到零。结义、单挑、计略、犒赏、流民和季节悬赏写在 `docs/规则配置规范.md` 的人事一节。搜索可以带回铁、木、皮、料或随身钱；学会形制之后自己锻造，坐骑用驯养。单挑可以吃到最多 4 点装备加成，军队结算不吃。统一之后的纪念馆按史书列人和事。演出说明在 [docs/spectacle.md](docs/spectacle.md)。`npm run sim` 用六个固定席位重跑对局，报告在 `docs/playtest-6bots.md`。

若环境里提供了 `DATABASE_URL`（`postgres://` 或 `postgresql://`），程序改用 Postgres。没有就用 SQLite。

裁判令牌在开局时只显示一次。第一号实验局如果要裁判，启动前设置 `TIANXIA_REFEREE_TOKEN`。令牌只能冻结作弊或骚扰，不能改战局。

## Docker

```bash
docker compose up --build
```

同样监听 4317。Compose 里的服务名是 `sanguo`。数据库文件仍在 `./data/tianxia.sqlite`。

## 已经实现

- 简体中文、English、日本語、한국어。史书按事件种类和参数，在打开时写成观看者的语言。
- 原创像素棋盘、立绘和芯片音乐。字体是 Fusion Pixel，SIL OFL。
- 空席只守城。臣服须超过三分之二才送出，刚好三分之二不通过。加入须接收一方的君主同意。
- 装备：搜索材料、购买、学习形制、锻造、驯养坐骑、穿戴卸下、军械捐献和领取。个人制作品可命名并记下制作者。
- 统一之后的纪念馆只列这一局里已经写下的势力和记载。
- 三支演出的像素分镜，以及跳过、关闭、省流、缺文件时回到像素。

## 还没有

- 没有部署好的线上对局。`npm run dev` 或 Docker 都是在你自己的机器上。
- 《刀锋借雨》和《名匠试锤》没有视频，只有分镜。
- 《主公验粮》有一支约 6 秒的 AI 概念样片，在 [examples/spectacle/](examples/spectacle/README.md)。游戏不自动播放它。清单地址是空的。样片不是可编辑的三维工程。
- 没有玩家之间的市场，军械不会自动发给别人，坐骑不能繁殖。
