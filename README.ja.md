# 三国全員オンライン

[中文](README.md) · [English](README.en.md) · [한국어](README.ko.md) · [貢献](CONTRIBUTING.ja.md)

導演のない三国。規則は公開する。統一すればサーバは閉じる。席は真人が坐る。空席は AI が命じない。古典の一回合は 24 時間。沙盤の演示は 8 分。回合を速めるのは、この企ての路線ではない。公式のオンラインサーバはない。複製したあと、自分の機械で動かす。

これは自分で配置できる社会実験であり、『覇王の大陸』や、どの商業ゲームの複製でもない。それらの美術、音楽、界面、数値表、地図は使わない。三国の人物と州郡は公共の歴史である。ここで継ぐのは、それだけだ。

倉庫が配るのは道具である。世界は運営しない。一局を他人に遊ばせる者は、その地の法の責任を負う。この企ては公式のサーバを持たず、料金も取らない。

「公式のない社会はいかに自ら組むか」を調べる企ては、自分のコードも同じ置き方をする。分叉は継げる。史書は消せない。

## この局で起こること

歴史上の席が十二。城が四。まだ搜索で見つかっていない在野の人物がいる。渾名は持ってこない。曹操を選べば、前には曹操しかいない。

毎回合、指令を一度出す。弾劾するか附議するか、屯田するか搜索するか、盟を結ぶか拒むか、出征するか固守するか。刻が来ればまとめて決する。空席は城を守るだけで、誰の代わりにも考えない。人物が戦死し、または処刑されたあと、永久に退場する。その名は次の者に渡さない。

誰かが都城と十分な城を握り、残る主要な勢力を滅ぼすか称臣させ、さらに守成を守り切れば、この局は記念館に入り、止まる。統一を不可能にするスイッチはない。全図を支配する（割合 1）は、配置の検証が拒む。

まずメニューを通したいなら、沙盤を開け。沙盤は席を換えられる。その記録は実験のデータにできない。

## 手元で動かす

Node.js 22。

```bash
npm install
npm test
npm run dev
```

ブラウザで `http://127.0.0.1:4317`。ホームに実験局が並ぶ。最初に開いたとき、庫に `demo` がなければ、程序が「第一号実験局」を自ら書く。档案は `tabletop_demo`。別の種子コマンドはない。棋盤は `http://127.0.0.1:4317/world/demo`。開発サーバは `0.0.0.0:4317` で聴く。ファイアウォールが許せば、同じネットワークからも届く。データは `data/tianxia.sqlite`。このファイルを写せば、一部の史書を控えたことになる。ファイル名と档案の識別 `tianxia_classic` は保存のための内部名で、ゲーム名に合わせて改めない。古い保存が外れないようにするためだ。

これは自分の機械での試遊であり、公衆網へ開いてよいサービスではない。身元はブラウザの `tx_session` クッキーだけで、アカウントはない。実験局は先に名を押した者が席を得る。クッキーを失えばその席へ戻れない。回合に背景の時計はない。誰かがページを開いて、初めて遅れを埋める。頻度の制限はこの一つのプロセスのメモリにある。倉庫に WebSocket はない。ポートを公衆網へ出さない。

棋盤は、この実験のために新しく描いた 8 ビットの瓦と矩形波の音。季節は色を換えて示す。雨、雪、霧、旱は点の粒。16 ビットには描き換えていない。古典の十二城は手で置いた。人物には各自の点描の立像がある。商業の三国ゲームの美術も曲も使わない。界面の字は融合像素（SIL OFL。`src/fonts/FONTS.md`）。簡体中文、English、日本語、한국어は、右上で切り替える。選択はこのブラウザに残る。覚えていなければブラウザの言語に従い、中国語の札はいずれも簡体の界面になる。史書が保存するのは出来事の種類とパラメータだけであり、開いた人の言語で文にする。右上の「有音」を押して初めて音が出る。天時の種子は開局の史書に書く。天気は公開された算法で再計算できる。減災と内政は行動点を共にする。堤防、義倉、医営、水渠、修路は公開された配置にある。満杯にしても損失を零にはできない。義盟、単挑、計略、犒賞、流民、季節の懸賞は `docs/rules.ja.md` の人事にある。搜索は鉄、木、革、飼料、または財布の銭を持ち帰る。形を覚えてから鍛える。乗騎は鍛えず、調える。単挑は装備で多くて 4 を足す。軍の決算は足さない。統一のあと、記念館はその局にすでに書いた人と記載を列する。演出の説明は [docs/spectacle.ja.md](docs/spectacle.ja.md)。`npm run sim` は六つの固定席で対局をやり直す。報告は `docs/playtest-6bots.md`。

環境に `DATABASE_URL`（`postgres://` または `postgresql://`）があれば Postgres を使う。なければ SQLite。

裁判の札は、開局のとき一度だけ示す。第一号実験局に裁判を置くなら、起動前に `TIANXIA_REFEREE_TOKEN` を置く。札が凍らせられるのは不正か嫌がらせだけで、戦局は改められない。

## Docker

```bash
docker compose up --build
```

同じく 4317 で聴く。Compose のサービス名は `sanguo`。データベースのファイルは、なお `./data/tianxia.sqlite`。

## すでにできること

- 簡体中文、English、日本語、한국어。史書は出来事の種類とパラメータを保存し、開いた人の言語で文にする。
- 創作の画素の棋盤、立像、チップの音楽。字体は Fusion Pixel、SIL OFL。
- 空席は城を守るだけ。臣従は三分の二を超えてから送る。ちょうど三分の二は不通過。加入は受け取る君主の同意を要する。
- 装備：材料の搜索、購入、形を学ぶ、鍛造、乗騎を調える、着脱、軍械への献納と受け取り。自ら打った品は名を付け、製作者を記す。
- 統一のあと、記念館はその局にすでに書いた勢力と記載だけを列する。
- 三つの演出の画素分鏡。飛ばす、切る、省流、ファイルが無いときは画素に戻る。

## まだないこと

- 配備済みの公開対局はない。`npm run dev` も Docker も、自分の機械で動く。
- 『刀は雨を借りる』と『名匠、槌を試す』に動画はない。分鏡だけ。
- 『主公、糧を験す』には約 6 秒の AI 概念見本がある。[examples/spectacle/](examples/spectacle/README.ja.md)。ゲームは自動では流さない。一覧のアドレスは空。見本は編集できる三次元の工程ではない。
- プレイヤー同士の市場はない。軍械は自ら人に渡さない。乗騎は殖やさない。
