# 「주공이 군량을 살피다」 견본

파일: [`grain-check-concept.mp4`](grain-check-concept.mp4)

저자가 받은 첫째 AI 개념 견본이다. 약 6초, 848×480. 전환이 튀고, 관리가 갑자기 나타나며, 웃을 자리도 아직 약하다. 저자는 이 판을 받아들이고, 더 만들지 않는다.

고칠 수 있는 3차원 공정이 아니다. 이 폴더에 장면, 샷, 공정 파일은 없다. 파일에 따로 된 허가서는 붙지 않았다. 상용 소재라고 쓰지 않고, 허가를 새로 만들지 않는다. 저장소의 코드는 그대로 [AGPL-3.0](../../LICENSE)이다.

게임은 이 파일을 스스로 재생하지 않는다. `public/spectacle/manifest.json`의 주소는 비어 있다. 건너뛰기, 절약, 끄기, 픽셀로 돌아가는 일은 그대로다. 「칼끝이 비를 빌다」와 「명장이 망치를 시험하다」는 아직 픽셀 분경뿐이고, 영상은 없다.
